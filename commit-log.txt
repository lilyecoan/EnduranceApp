Data sources (Intervals.icu, Strava, file upload), Cloud Run deploy, auth fix

- Athletes pick their data source on Settings: Intervals.icu (OAuth or
  personal API key; workouts + HRV/sleep/resting HR/weight/CTL/ATL),
  Strava (workouts only, excluded from AI input per Strava's API terms),
  or file upload (.fit, zips incl. Garmin "Export Your Data", Apple
  Health export). Provider tokens are Fernet-encrypted; OAuth state is
  signed and user-bound; disconnect revokes access and deletes data.
- Dashboard/coaching snapshot now comes from the athlete's own data and
  never falls back to the shared GARMIN_EMAIL login (which served one
  person's real Garmin data to every user).
- Migration 0002: data_connections, per-source recovery records,
  per-user activity de-duplication (safe on fresh and existing DBs).
- Fix Clerk JWKS fetch failing with CERTIFICATE_VERIFY_FAILED on macOS
  Python by using certifi's CA bundle (cause of the dashboard 401s).
- Cloud Run deploy script (secrets in Secret Manager, Neon Postgres);
  Docker installs from requirements.lock.txt, since requirements.txt pins
  were stale and unresolvable.
- Auto-export redacted session transcripts via a Stop hook.
